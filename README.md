# react-portfolio

My personal portfolio website created in React (Vite + Tailwind). Includes a contact form backed by a small Node/Express server.

## Run locally

- **Backend:** `cd server && npm install && npm start` (runs on port 4000; set `GMAIL_APP_PASSWORD` in `.env` for the contact form).
- **Frontend:** `cd react-portfolio && npm install && npm run dev` (then open the URL Vite prints).

## Deploy for free (no Vercel)

Frontend → **GitHub Pages** · Backend → **Render**. Full steps: see **[DEPLOY.md](./DEPLOY.md)**.
